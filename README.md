# Ayrık Matematik - 2. Hafta Ödevi

Bu depoda, Ayrık Matematik dersi 2. hafta ödevi kapsamında çözülmüş sorular ve adım adım çözüm aşamaları yer almaktadır.

## İçerik
- **Önerme Kavramı ve Doğruluk Değerleri:** Verilen ifadelerin önerme olup olmadığının ve doğruluk değerlerinin tespiti.
- **Doğruluk Tabloları:** Mantıksal bağlaçlar ($\wedge, \vee, \Rightarrow$) içeren bileşik önermelerin doğruluk tablolarının oluşturulması.
- **Mantıksal Denklikler & De Morgan Kuralları:** Bileşik önermelerin sadeleştirilmesi ve değilinin (olumsuzunun) bulunması.
